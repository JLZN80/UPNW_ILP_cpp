# UPNW_PP_cpp

Repositorio de ejercicios, ejemplos y desarrollos en C++ para el curso de **Principios de Programacion** de la **Universidad Privada Norbert Wiener (UPNW)**.

Este espacio reune codigos trabajados en clase, practicas semanales, ejercicios tipo parcial y pequenos retos pensados para que los estudiantes puedan practicar, equivocarse, corregir y fortalecer su razonamiento algoritmico.

## Proposito

El objetivo de este repositorio es dejar a disposicion de los alumnos una base de ejercicios progresivos que les ayude a:

- Practicar la sintaxis basica de C++.
- Comprender el uso de variables, operadores, condicionales y ciclos.
- Resolver problemas mediante pensamiento logico y algoritmico.
- Revisar ejemplos similares a los trabajados en clase.
- Prepararse para practicas, controles y evaluaciones parciales.
- Comparar distintas formas de plantear una solucion.

La intencion no es solo entregar codigo terminado, sino ofrecer material que sirva como punto de partida para analizar, modificar y mejorar soluciones.

## Contenido del repositorio

La organizacion puede ir creciendo durante el ciclo academico. Actualmente se incluyen carpetas como:

- `Week 6/`: ejercicios y ejemplos desarrollados durante la semana 6.
- `Week 7/`: ejercicios y ejemplos desarrollados durante la semana 7.
- `Week 9/`: ejercicios de estructuras, arreglos de estructuras y manejo de registros en C++.
- `ExParcial/`: ejercicios tipo parcial y material de practica para evaluacion.

Cada archivo `.cpp` contiene un ejercicio independiente o una demostracion puntual de algun concepto del curso.

## Como usar estos ejercicios

Se recomienda que los estudiantes no copien directamente las soluciones. Una mejor forma de trabajar es:

1. Leer el enunciado o identificar que problema resuelve el codigo.
2. Intentar resolverlo primero sin mirar la solucion completa.
3. Ejecutar el programa y probar distintos casos.
4. Modificar entradas, condiciones o formulas para observar cambios.
5. Reescribir la solucion con sus propias palabras y estilo.
6. Agregar validaciones o mejoras cuando sea posible.

## Como compilar

Para compilar un archivo de C++ con `g++`, se puede usar un comando como:

```bash
g++ "ExParcial/Q1.cpp" -o programa
```

Luego se ejecuta:

```bash
./programa
```

En Windows, si se genera un `.exe`, puede ejecutarse asi:

```bash
programa.exe
```

Tambien se puede trabajar desde editores como Visual Studio Code, Dev-C++, Code::Blocks u otro entorno configurado para C++.

## Recomendaciones para estudiantes

- Ejecuta el codigo, no te quedes solo leyendolo.
- Cambia valores y prueba casos limite.
- Comenta las lineas que no entiendas y revisalas en clase.
- Practica escribir el mismo ejercicio desde cero.
- No memorices soluciones: entiende el proceso.
- Usa estos ejemplos como guia, no como reemplazo de tu propio razonamiento.
